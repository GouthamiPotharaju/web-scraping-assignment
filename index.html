Pipeline

Design decisions

Pagination: follows the li.next > a link until none remains; no hard-coded page numbers.

Failures: session retries (1s/2s/4s backoff) on 429/5xx and dropped connections; a bad record is skipped, a failed page stops only that source.

Deduplication: books use source + title + price; quotes use source + author + first 50 characters. Price was added after the real data showed two different books titled "The Star-Touched Queen" (£46.02 and £32.30), which a title-only rule had wrongly merged.

Descriptions: the site's HTML repeats a truncated copy of each description and sometimes has mis-encoded characters; both are cleaned.

Common schema

source source_url name_or_title category price rating author tags description scraped_at. Fields that do not apply to a source are left empty, never invented.
